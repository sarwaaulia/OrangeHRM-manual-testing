# **Test Plan \- Employee Management & Leave Management Module**

# **1\. Objective** 

This test plan aims to verify that the Employee Management and Leave Management modules function according to the specified business requirements, ensuring correct functionality, data integrity, and proper validation. 

# **2\. Scope**

1. ##  **In-Scope**

* Login functionality 
* Employee management (add employee, view employee details, edit employee, delete employee)  
* Leave management functionality  (apply leave, approve leave, reject leave, cancel leave)  
* Search and filtering functionality  
* Field validation  
* Error message validation

2. ##  **Out-of-Scope**

* API testing (handled separately)  
* Performance testing (outside current testing scope)  
* Security testing (not included)  
* Database validation (no direct database access)

# **3\. Test Strategy**

This testing was conducted using a manual black-box testing approach to evaluate the success and scope of the features being tested.  
Input validation will be verified using valid, invalid, boundary, and empty input values.

 

# **4\. Environment**

* URL: [https://opensource-demo.orangehrmlive.com](https://opensource-demo.orangehrmlive.com/)/   
* OS: Windows 11  
* Browser: Google Chrome Version 138    
* Environment: Public Demo Environment  
* Testing Type : Manual Testing 

# **5\. Entry Criteria**

* Demo site accessible  
* The test environment is accessible.  
* A test account is available.  
* Business requirements are available.  
* Test cases have been prepared. 

# **6\. Exit Criteria**

* All planned test cases executed.  
* No open Critical defects remain.   
* Test Summary Report completed.   
* Acceptance Criteria achieved. 

# **7\. Risks**

* Limited testing time  
* Demo environment instability  
* Test data dependency  
* Browser compatibility limitations

# **8\. Acceptance Criteria**

* No Critical defects remain open   
* No High severity defects remain open.   
* 100% of high-priority test cases passed.  
* Overall pass rate ≥ 90%.   
* All blocking defects have been resolved.
